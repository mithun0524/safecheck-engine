# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within SafeCheck, please DO NOT open a public issue.

Instead, please send an email to `security@example.com` (Update this before launch).
We will review all reports and respond as quickly as possible.

## Supported Versions

Currently, SafeCheck is in pre-release development. No versions are officially supported for production yet.
Once version 1.0.0 is released, this section will detail the support windows for stable releases.

## Response Expectations

- **Acknowledgment:** We aim to acknowledge vulnerability reports within 48 hours.
- **Triage:** We will triage the vulnerability within 5 business days and provide an estimated timeline for a fix.
- **Remediation:** We will keep you updated on the progress of the remediation.

## Technical Security Architecture

For detailed information regarding our threat model, internal security architecture, and development constraints, please see our internal [Technical Security Documentation](docs/SECURITY.md).
